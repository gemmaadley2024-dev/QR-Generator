# GitHub Pages Setup

After uploading this ZIP to GitHub:

1. Open your repository.
2. Go to **Settings**.
3. Go to **Pages**.
4. Select **Deploy from a branch**.
5. Select:
   - Branch: `main`
   - Folder: `/root`
6. Click **Save**.

Your live URL will look like:

```text
https://yourusername.github.io/repository-name/
```

Later, when IT gives you a company domain, add it under **Custom domain**.
